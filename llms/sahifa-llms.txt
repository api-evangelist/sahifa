# Sahifa

> HTML to PDF and screenshot API hosted in Jeddah, Saudi Arabia. Request content and rendered documents are processed only in the Kingdom and never stored, which supports SAMA and PDPL data residency. Drop-in compatible with PDFShift v3 (POST /v3/convert/pdf) and ScreenshotOne (/take). Operated by Yimello LLC (UAE).

Base URL: https://api.sahifa.dev. Authentication: X-API-Key header (Basic auth "api:KEY" on /v3/convert/pdf and access_key on /take also work). Renders have no side effects, so retries are safe. Free Sandbox key: https://sahifa.dev/en/account
